How to scan a place
  1. Stand in the room and tap Start place scan. Allow camera access.
  2. Move the phone slowly, like spray-painting: floor, each wall, then furniture from a couple of angles.
  3. Watch the dots fill in on screen. Gaps mean that area still needs a pass.
  4. Tap Finish when done. About a minute covers a small room.
  5. Glass, mirrors, shiny and very dark surfaces don't give depth and will stay empty.

How to shoot for a good model
  1. Easiest: use Continuous shoot or Record video and turn the object one full circle at a steady speed (20–30 seconds), going a little past where you started.
  2. Plain background. Put the object on a sheet or wall that is a different colour from it. White object? Use a dark cloth.
  3. Keep it all in frame with some space around it. The object must not touch the photo edges.
  4. Hold the phone still (prop it on books or a tripod). Turn the object by the same step each time, on a lazy susan or the mat below.
  5. No turntable? Walk around it in a circle, same distance and height, and choose Hand-held in step 3.
  6. Go all the way round in one direction. 24 photos is a good start; 36 for detailed shapes.
  7. Even, soft light. Avoid hard shadows on the background.

The app cuts the object out of each photo (cyan). The model can only be as good as these cut-outs, so tune until every photo shows the whole object and no background.
The zip holds model.glb (real size in metres, for AR apps and Windows 3D Viewer), model.obj and model.ply with colours (Blender, MeshLab) and model.stl for 3D-printing slicers. OBJ/PLY/STL are in centimetres, scaled to the height above.
This builds the shape from the object's outline in every photo, so it captures the overall form well but fills in hollows like the inside of a cup or the gap under an arm. Solid, chunky objects scan best.

Installing the APK
  1. Scan the code with the phone's camera and open the link. hulma-3d.apk downloads.
  2. Open the file. If Android asks, allow Install unknown apps for your browser.
  3. If Play Protect warns about an unknown app, tap More details, then Install anyway.
  4. Hulma runs inside Chrome, so keep Chrome installed and updated. AR also needs Google Play Services for AR.
  5. The first launch needs internet. After that it opens offline too.
  6. New builds install over the old one, and the same QR code always gets the newest version.
